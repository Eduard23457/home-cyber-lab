# Lab 01: Windows Server + Active Directory

## Цель
Развернуть Windows Server 2022, настроить AD, DNS, DHCP, создать пользователей и ввести клиента в домен.

## Что делаем
1. Установка Windows Server 2022
2. Настройка статического IP
3. Установка AD DS, создание домена lab.local
4. Настройка DNS
5. Настройка DHCP
6. Создание OU, групп, пользователей
7. Настройка прав на папки
8. Ввод Windows 10 в домен
